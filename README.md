# Atmos

Atmos is a cinematic atmospheric rendering mod for Minecraft Fabric 1.21.1.

Atmos enhances Minecraft with soft biome-aware fog, immersive environmental blending, cinematic weather mood, and dreamy exploration-focused visuals while remaining lightweight and vanilla-friendly.

---

# Features

## Cinematic Fog

Atmos introduces:

* Soft distance haze
* Biome-aware fog profiles
* Smooth fog transitions
* Height-based atmosphere
* Dynamic environmental mood
* Weather-aware rendering
* Exploration-focused visibility

---

## Biome Atmosphere

Each biome has unique atmospheric tuning:

* Jungle mist
* Desert heat haze
* Snow storms
* Swamp fog
* Ocean atmosphere
* Forest haze
* Cave depth fog
* Mushroom biome ambience

---

## Smooth Environmental Blending

Atmos smoothly blends:

* Fog distance
* Fog density
* Fog color
* Environmental transitions

This prevents harsh visual popping while traveling across the world.

---

# Design Philosophy

Atmos aims to make Minecraft feel:

* Cinematic
* Dreamy
* Immersive
* Atmospheric
* Soft
* Alive

while still preserving gameplay readability and vanilla identity.

Atmos is NOT intended to become:

* An ultra-realistic simulator
* A blurry visibility-destroying fog overhaul
* A heavy performance-cost shader replacement

The goal is balance.
